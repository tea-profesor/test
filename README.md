# Mini Arcade — Telegram Mini App

Мини-приложение для Telegram с главным меню и разделами «Играть», «Друзья», «Магазин», «Новости». Сделано как статический сайт без сборки: чистые HTML, CSS и JavaScript, официальный Telegram WebApp SDK лежит локально.

## Структура

```
index.html              разметка экранов и главное меню
styles.css              оформление, адаптив, safe-area, анимации
app.js                  навигация, Telegram WebApp API, haptics, профиль, магазин
game.js                 игра от первого лица, бой, скины и MQTT-мультиплеер
store.js                монеты, покупки, скины и сохранение прогресса (CloudStorage)
three.min.js            Three.js r128, MIT (вендор)
mqtt.min.js             MQTT.js 5.10.1, MIT (вендор, браузерная сборка)
telegram-web-app.js     официальный Telegram WebApp SDK (вендор)
.nojekyll               отключает Jekyll на GitHub Pages
```

## Локальный запуск

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080`. Вне Telegram приложение работает в браузере в режиме гостя.

## Деплой на GitHub Pages

1. Создать публичный репозиторий и запушить ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

Для автоматической настройки через API токену нужны права:

- **Contents: Read and write** — чтобы пушить код;
- **Administration: Read and write** — чтобы создавать репозиторий;
- **Pages: Read and write** — чтобы включить GitHub Pages.

## Подключение к Telegram

Бот: [@ligigark_bot](https://t.me/ligigark_bot), приложение: `https://tea-profesor.github.io/test/`.

1. У [@BotFather](https://t.me/BotFather) выполнить `/setmenubutton`, выбрать `@ligigark_bot`.
2. Указать URL `https://tea-profesor.github.io/test/` и текст кнопки `Играть`.
3. Открыть бота и нажать кнопку меню — Mini App запустится внутри Telegram.

Для продакшена рекомендуется собственный домен: Telegram требует HTTPS, GitHub Pages его даёт по умолчанию.

## Что уже работает

- Вертикальное меню: Играть → Мультиплеер → Друзья → Магазин → Новости → Чат.
- Переходы между экранами с анимацией, кнопка «Назад» и системная кнопка Telegram.
- Данные пользователя из `initDataUnsafe`: имя, username, аватар.
- Тактильный отклик, безопасные отступы, тёмная неоновая тема.
- Раздел «Друзья» с приглашением через `t.me/share/url`.
- Экран «Чат» с переходом в группу сообщества (ссылка задаётся в `CHAT_URL`).
- Игра «Зелёная карта»: вид от первого лица, джойстик движения, кнопки прыжка и атаки, шкала HP 100, враги без возрождения, возрождение игрока при потере HP.
- Монеты: +100 за каждого побеждённого врага, баланс в HUD и магазине.
- Босс: после победы над всеми врагами появляется главный босс с 1000 HP, атакой 10 и наградой 1000 монет.
- Магазин: лук бесконечных стрел за 300 монет, 6 скинов (Разведчик бесплатно, остальные 400–1200 монет).
- Скины меняют цвет оружия, прицела и аватара в сети; покупка сразу надевает скин.
- Мультиплеер до 5 игроков: комната по 5-символьному коду, общие позиции и скины через публичный MQTT over WSS (`broker.hivemq.com`).
- Сохраняется всё: монеты, лук, скины, убитые враги и HP босса — через Telegram CloudStorage и localStorage. Монеты и покупки уходят в облако сразу, плюс есть принудительная синхронизация при сворачивании.
- Кнопка «Начать бой заново» в магазине возвращает врагов и босса, не сбрасывая монеты и покупки.

## Управление в игре

- Левый нижний угол — джойстик движения.
- Свайп по экрану — обзор.
- Атака — меч, а после покупки лука — стрелы (бесконечно).
- Правый нижний угол — прыжок, над ним — атака.
- Левый верхний угол — здоровье (100).
- Кнопка «Сеть» справа сверху — создать комнату или войти по коду.

## Мультиплеер: ограничения

- Враги и урон считаются локально у каждого игрока — это кооперативное присутствие, а не общий бой.
- Комната живёт, пока в ней есть подключённые игроки; история сообщений не хранится.
- Публичный брокер HiveMQ не требует аккаунта, но код комнаты — единственный ключ доступа. Не передавайте личные данные.
- При выходе из экрана игры или сворачивании приложения комната закрывается.
